# 엔딩 스토리 맵 '자정의 시계판' — 녹아내리는 섬 아랫면 키트 명세 (2026-11-26)

사용자 요청: "맵 아랫부분도 블렌더로 따로 더 깎아서 녹아내리는 느낌을 더 줘야 할 것 같은데 지금 좀 이상함".
지금 섬 아랫면은 마을 가장자리 바위 조각(Edge_A/B/C)만 둘레에 붙어 있어서, 위에서 내려다보면 섬이 얇은 판처럼 떠 있고 아래가 비어 보임.
엔딩 = 꿈의 마을이 끝나는 순간. 섬 아래가 **촛농 · 녹은 모래 · 녹은 금처럼 아래로 흘러내리다 방울져 떨어지는** 모습이어야 함.

블렌더 스크립트 `Art/tools/blender_kit_story_dial_under.py` (헤드리스:
`"C:/Program Files/Blender Foundation/Blender 5.3/blender.exe" -b --factory-startup -P Art/tools/blender_kit_story_dial_under.py`)
→ `Game/Assets/Art/Characters/StoryDial/Kit_D_Under_<Key>.fbx` + `Kit_D_Under_<Key>_tips.json`
→ 유니티 메뉴 `CatTang/엔딩 시계판 아랫면 키트 만들기` → `Resources/Kit/StoryDial/Under_<Key>.prefab` → `CatTang/엔딩 스토리 맵 시계판 조립`이 섬마다 붙임.

## 입력: 섬 윤곽
`Art/tools/specs/story_dial_outlines.json` (UTF-8): 섬 6개 `Center` `Gun` `Ammo` `Wardrobe` `Cuckoo` `Gate`.
각 항목 `center` = 맵 안 섬 중심 (유니티 x, z), `outline` = 섬 윗면 바깥 둘레 72점 (섬 중심 기준 유니티 로컬 x, z, 반시계 아님 · 시계 방향일 수 있으니 방향을 확인해서 씀).
**블렌더 좌표 = (outline x, outline z, 높이)**. 섬 윗면(걷는 땅)은 유니티 높이 0.01. 아랫면 조각은 **블렌더 Z ≤ −0.05** 에만 있어야 함(윗면을 뚫고 올라오면 안 됨).
가운데 섬(Center)은 지름 약 22m, 바깥 섬은 약 18m.

## 조각 (6개, 이름 = `Under_<Key>`, 원점 = 섬 중심 · 윗면 높이 (0,0,0) 그대로 = KEEP, 중심 보정 하지 말 것)
하나마다:
1. **윗입술(lip)**: 윤곽을 0.15m 안으로 줄인 고리, Z −0.05 ~ −0.7, 바깥으로 살짝 불룩(0.2m) — 섬 윗면 가장자리 바로 아래를 덮는 두꺼운 흙 띠(`sand` 위 · `earth` 아래, 경계가 물결).
2. **몸통(melt body)**: 윤곽에서 아래로 내려가며 좁아지는 고리를 6~8단으로 쌓은 불규칙한 뒤집힌 언덕. 깊이 = 바깥 섬 8~10m, 가운데 섬 7m.
   단마다 반지름을 줄이되 각도마다 줄어드는 정도를 다르게(시드 노이즈) 해서 **한쪽으로 처지고 늘어진** 실루엣. 맨 아래는 뾰족한 한 점이 아니라 2~3갈래로 갈라져 흘러내린 끝.
   재질 띠(높이 + 노이즈로 물결 경계): 위 `sand` → `earth` → `rock` → `rock_dark`, 사이사이 `root` 가는 뿌리 몇 가닥이 몸통 겉을 타고 내려옴.
   **가운데 섬**: 유니티에서 높이 −6.5에 거대한 시곗바늘 두 개가 섬 중심에서 바깥(북쪽 +Y)으로 뻗음 → 가운데 섬 몸통은 Z −5 아래에서 반지름 4m 이하로 좁혀서 바늘이 r 5m부터 보이게.
3. **흘러내림(drips)**: 섬 둘레 입술과 몸통 겉에서 아래로 늘어진 촛농 · 녹은 모래 줄기 10~16개(가운데 섬 16, 바깥 섬 10~12).
   굵기 0.25~0.7m에서 아래로 갈수록 가늘어지다 끝에 둥근 방울(지름 줄기 굵기 × 1.4). 길이 1.5~7m, 짧고 긴 것을 섞고 몇 개는 몸통 아래 끝보다 더 내려옴.
   절반은 몸통 겉에 붙어 흐르는 띠(표면을 따라가는 리본 · 두께 0.1~0.2), 절반은 공중에 매달린 줄기.
   재질: 줄기 `sand` · `earth` (흙이 녹은 것) 6할, `gold_drip`(녹은 금) 3할, `sand_glow`(빛나는 시간 모래) 1할. 방울 끝은 같은 재질의 밝은 쪽(`gold` · `sand_glow`).
   **떨어지는 방울**: 줄기 끝 아래 0.4~1.5m에 떨어져 나온 작은 방울 1~2개(지름 0.12~0.3, 같은 재질)를 공중에 둠.
4. **박힌 시계 조각**: 몸통 겉에 반쯤 박힌 톱니바퀴(`brass` · 반지름 0.4~0.9, 이빨) 3~5개, 작은 문자판 조각(`clock_face` 원판 + `iron` 눈금 막대) 2~3개, 휘어서 늘어진 시곗바늘(`iron`) 1~2개 —
   몇 개는 녹아서 아래로 처짐(달리의 녹는 시계처럼 아래 가장자리가 늘어짐).
5. **빛나는 금(cracks)**: 몸통 겉 세로 균열 4~6줄(`sand_glow`, 폭 0.08~0.15, 얕게 튀어나온 띠).

장식 규칙(사용자 요구, 단색 덩어리 금지): 조각마다 역할 재질 6~8가지, 한 재질이 겉면 55%를 넘지 않게. 0.04m보다 가는 것 없음. 시드 고정(섬 이름마다 다른 시드).
삼각형 예산: 가운데 섬 18000, 바깥 섬 14000 (넘으면 decimate).

## 방울 끝 위치 sidecar (유니티 파티클 자리)
`Kit_D_Under_<Key>_tips.json` = 공중에 매달린 줄기 끝 방울 중심 좌표 목록 **유니티 좌표 (x, y, z) = 블렌더 (x, z, y)**, 섬 원점 기준. 예: `{"tips": [[1.2, -6.3, 0.4], ...]}`.
유니티가 거기서 금빛 방울 · 모래가 떨어지는 파티클을 냄.

## 2차 보강 (2026-11-26, 1차 결과를 게임 카메라로 본 뒤)
1차는 아랫면이 얕은 사발 모양이라 **위에서 비스듬히 내려다보는 게임 카메라에선 섬 가장자리 너머로 녹아 넘치는 게 거의 안 보임**. 다음을 더함:
1. **가장자리 흘러넘침(rim overflow lobes)**: 섬 윤곽을 따라 1.5~2.5m마다 촛농처럼 가장자리를 넘어 흘러내린 둥근 주름 덩어리.
   윗면은 입술 위(Z −0.05)에서 시작해 윤곽 **바깥으로 0.1~0.5m** 불룩 나왔다가(Z −0.05 아래면 윤곽 밖으로 나가도 됨) 1~3m 아래로 처지며 둥글게 맺힘.
   **남쪽 반(블렌더 −Y, 카메라 쪽)에 6할**. 재질 `sand` · `earth` · `gold_drip`(3할) 섞어서, 덩어리 아래 끝에 방울.
2. **흘러내림 줄기 두 배**: 가운데 섬 30, 바깥 섬 20. 길이 2~10m, 굵기 0.35~0.9m. 절반 이상은 흘러넘침 덩어리 아래 끝에서 시작해 **윤곽 바로 바깥(0~0.6m)** 에 매달림 → 위에서 내려다봐도 섬 가장자리 밖으로 늘어진 줄기가 보이게.
3. **몸통 혀(melt tongues)**: 몸통 겉에서 폭 1.5~3m · 길이 4~8m 큰 혀 모양 덩어리 3~5개가 한쪽으로 처져 늘어지고 끝에서 줄기 2~3개로 갈라짐. 몸통은 더 비대칭으로 처지게.
4. 삼각형 예산: 가운데 섬 26000, 바깥 섬 20000. 재질 규칙 · 원점 · tips json(공중에 매달린 줄기 끝 전부) 그대로.

## 3차 — 물방울 말고 흘러내리는 모래 (2026-11-26 사용자: "흘러내리는 모래처럼 표현해줘 · 물방울 처리 하지 말고")
2차는 끝마다 둥근 방울이 맺혀 **물 · 촛농처럼 보임** → 모래로 바꿈. 위 1~3의 배치 · 양은 그대로 두되 모양 · 재질을 이렇게:
- **둥근 방울 전부 없앰**: 줄기 끝 구슬, 공중에 떨어진 방울, 덩어리 아래 끝 방울 모두 삭제. 매끈하고 반질한 액체 모양 금지.
- **흘러넘침 덩어리 → 모래 사태**: 가장자리를 넘어 흘러내린 모래 더미. 겉에 가로 물결 자국(모래 언덕 리플, 굵기 0.05~0.1 띠)과 층층이 무너진 계단 턱, 아래로 갈수록 거칠게 부서진 가장자리.
- **줄기 → 쏟아지는 모래 기둥**: 위는 굵고 아래로 갈수록 가늘어지다 **끝이 뾰족하지 않고 흩어지며 사라짐** — 기둥 아래 1/3은 몸통에서 떨어져 나온 작은 모래 알갱이 덩이(0.06~0.15 각진 조각 6~14개)가 줄기를 따라 점점 듬성하게 흩어짐. 겉에 세로 홈.
- **몸통 혀 → 모래가 흘러내린 자국**: 혀 모양은 유지하되 겉을 세로 줄무늬 · 리플로, 끝은 갈라진 모래 줄기 여러 가닥이 흩어지며 사라짐.
- **재질**: 모래 `sand` · `sand_glow`(빛나는 시간 모래, 줄기 안쪽 · 리플 띠) · `earth` 위주, **`gold_drip` 은 쓰지 않음**. `gold` · `brass` 는 박힌 시계 조각에만. 몸통 띠 `rock` · `rock_dark` 그대로.
- tips json = 각 모래 기둥이 흩어지기 시작하는 곳(기둥 아래 1/3 지점)과 흘러넘침 사태 아래 끝 — 유니티가 거기서 가는 모래 줄기 파티클을 쏟음.
