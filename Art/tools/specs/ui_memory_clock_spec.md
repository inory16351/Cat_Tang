# 추억 표식 시계 아이콘 1장

이미지 생성 도구로 작은 시계 아이콘을 그려 `Game/Assets/Resources/UI/memory_clock.png`로 저장한다.
- 쓰임: (1) 추억 특성 탄에 맞은 적 몸 위에 반투명하게 떠서 종처럼 흔들리며 '울리는' 연출, (2) 적 머리 위 체력 바 옆에 표식 개수 숫자와 함께 붙는 작은 아이콘(화면에서 30~40px).
- 모양: 둥근 회중시계/탁상시계 문자판 하나, 위에 작은 꼭지(용두) 또는 종 두 개 달린 자명종 느낌, 바늘 두 개, 눈금 4개 정도만 (작게 봐도 읽히게 단순하게). 글자 · 숫자 없음.
- 화풍: HUD와 같은 놋쇠 — `docs/images/ui` 아래 HUD 그림(가운데 시계 · 실린더 · 체력 틀)과 `Game/Assets/Resources/UI/hp_frame.png`를 열어 보고 같은 재질. 어두운 놋쇠 테두리, 크림색 문자판, 굵은 거의 검은 외곽선, 광택 적게, 평평한 셀 셰이딩.
- 투명 배경 PNG, 512×512, 진짜 알파 (체크무늬 금지, 단색 배경이면 지워서 알파로).
- 저장 후 크기 · 알파 확인하고 경로만 출력.
