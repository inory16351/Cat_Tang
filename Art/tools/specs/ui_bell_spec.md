# 종 아이콘 다시 (고양이 머리 위 표시용) — v2 놋쇠 HUD 통일

이미지 생성 도구로 종 아이콘을 다시 그려 `Game/Assets/Resources/UI/bell_icon.png`를 덮어쓴다.
- 1차(반짝이는 이모지풍 금종)는 게임과 안 어울린다는 사용자 피드백. **HUD와 같은 놋쇠 스타일**로.
- 화풍 기준: `Game/Assets/Resources/UI/hp_frame.png` · `head_dash.png`와 `docs/images/ui` 아래 HUD 그림(시계 · 실린더 · 체력 틀)을 열어 보고 같은 재질 — 어두운 놋쇠/청동, 갈색 그림자, 굵은 거의 검은 외곽선, 광택 적게(하이라이트는 가는 선 한두 줄), 평평한 셀 셰이딩. 테두리에 작은 리벳 · 톱니 장식 하나 정도.
- 모양: 작은 종 하나 + 추, 울림 선은 없거나 아주 짧게. 실루엣이 작은 크기(화면에서 40px 안팎)에서도 읽히게 단순하게.
- 투명 배경 PNG, 512×512, 진짜 알파 (체크무늬 금지, 단색 배경이면 지워서 알파로). 글자 없음.
- 저장 후 크기 · 알파 확인하고 경로만 출력.
