# 11:59 러시아어(ru) 번역 용어집

`docs/loc_glossary.md` (한국어 → 영어) 의 러시아어 열. 사전 `Game/Assets/Resources/Lang/ru.json`. 번역 전에 정하고 끝까지 지킴.

## 문체 (Стиль)

| 대상 | Русский стиль |
|---|---|
| UI · 안내 | Чётко, нейтрально, единообразно. Обращение на «вы», повелительное наклонение («Перетащите патрон…»). Кнопки и ярлыки — коротко (≤ ~1,3× английского), с заглавной буквы только первое слово (кроме имён собственных). |
| Ярлыки с числом | Конструкции без согласования с числом: «Осколки времени: {0}», «×{0}», «{0} шт.», «{0} с», «Ячейка {0}», «Глава {0}». Существительное перед числом или через двоеточие. |
| Фрагменты (` · `, `{0}`) | Именительный падеж / форма ярлыка, чтобы части читались при склейке. |
| Подсказки босса | Короткое повелительное «ты»-обращение + «!» («Встань в безопасную зону!»). Структура « — » сохраняется. |
| Кот | Немногословный стрелок Дикого Запада. Короткие фразы, на «ты» со всеми, грубоватость не сильнее «Чёрт». Мужской род. |
| Зеркальный кот | Спокойный, мягкий, тихий. На «ты». Мужской род. |
| NPC | Существа, поглощённые временем: полузабытые фразы, медленный, мягкий ритм, многоточия. Кузнец — тяжело и коротко; Портниха — мягко (женский род); Шериф — старый киногерой вестерна; Привратник — торжественно. Все, кроме Портнихи, — мужской род. |
| Сны (описания кадров) | Короткие именные группы, стиль раскадровки («Морщинистые руки заводят пружину (крупный план)»). |

## Символы · формат

- Многоточие в репликах — три ASCII-точки `...`, количество точек как в оригинале (`......` → `......`). `…` только если он есть в оригинале.
- `{0}` `{1}` — все сохраняются, порядок можно менять. Теги `<color=…>` `<size=…>` `<b>` `<i>` — без изменений, парно.
- ` · ` ` — ` `×` `÷` `+` `−`, двойные пробелы — как в оригинале. Без пробелов в начале/конце.
- Числа в тексте оригинала не меняем (десятичная точка остаётся `.`, как у чисел, подставляемых движком).
- Единицы: `초` → `с` (после числа: «{0} с»), в предложении — «сек.»/«секунд» только там, где число не подставляется; `발` → «выстр.» / конструкция «выстрелов: {0}»; `칸` → «ячейки: {0}» / «Ячейка {0}»; `개` → «{0} шт.» или «…: {0}».
- `{0}시`: в ярлыках «Час суда {0}», «Ячейка {0}», в предложении — «{0} ч» / «на {0} часах» (где число стоит после предлога и не склоняется).
- Клавиши: Space, Tab, Esc, E, Q, WASD, M — латиницей. 좌클릭 / 우클릭 → ЛКМ / ПКМ (в ярлыках и подсказках клавиш), «левый клик» / «правый клик» внутри предложений. 휠 클릭 → СКМ.
- Кавычки «ёлочки» — только если в оригинале есть кавычки. «11:59» не переводится.
