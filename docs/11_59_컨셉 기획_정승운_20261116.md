## 핵심 재미 요소
- 다양한 상황과 드랍된 아이템에 맞추어 빌드를 전략적으로 구성
- 화려한 액션과 이펙트를 통해 완성된 빌드에 대한 피드백을 강하게 전달 -> 유저에게 성취감 전달

## 컨셉과 세계관
- 내부 스토리(인 게임) - 정지된 시간의 공간에 갖힌 고양이 사수가 탈출하기 위해 사투를 벌임
- 외부 스토리(아웃 게임) - 동화 속 주인공인 고양이 사수가 늙은 시계공의 죽음을 앞둔 마지막 1분을 반복. -> 죽음을 받아들이고 떠남 / 정해진 운명은 받아들여야 한다는 감동적 스토리 연출

## 원페이지 기획서
- 레퍼런스 게임: 하데스 / 스컬 / 세피리아
## 비쥬얼 가이드
- 내부 비쥬얼 레퍼런스: 하데스 -> 해칭과 명암대비를 강하게, 강렬한 잉크 표현
- 구현방안: 플랫하게 디테일을 제외한 시안을 통해 이미지를 생성 후, 툰 셰이더로 손 그림 효과를 더하고, 상기 비쥬얼을 구현
- 이펙트나 아이콘은 2d / 오브젝트, 맵 디자인, 캐릭터와 몬스터는 3d 모델링으로 구현
- 셰이더는 2d / 3d 통일하여 적용
- 인게임 그림체(2026-11-17 확정): 브롤 스타즈풍 -> 플랫하면서 가시성 높게. 그림자는 1단, 고양이와 몬스터는 채도를 올리고 검은 외곽선 + 얇은 흰 림으로 배경과 분리
- 타격 연출(2026-11-17 확정): 특성마다 고유 색 / 고유 타격 이펙트, 극한 회피는 회색 화면 + 슬로우 + 하늘색 리본, 조준 커서는 밑색을 반전하는 조준선

## 레벨 디자인
- 이야기 루프 흐름(5개 챕터)
	- 고양이 사수의 컨셉을 연결 시켜 일그러진 서부 마을에서 시작
	- 초현실주의적으로 몽환적 느낌을 스토리의 진행에 따라 점차 강조하여 스토리 컨셉을 반영하고, 강해진 적들의 느낌을 시각적 피드백으로 전달
- 각 챕터는 4개의 스테이지와 1개의 보스 스테이지로 구성
- 각 스테이지는 4~5개의 전투방으로 이루어지고, 모든 적을 처치하면 해당 스테이지를 클리어 처리 후 보상 지급
- 선택형 보상(선택지 3개) - 총탄, 총, 연산
- 확정형 보상 - 방어구 강화, 골드, 시간의 조각
- 전투방을 클리어하면 15% 확률로 골드로 총탄 / 총 / 연산 / 하트를 판매하는 상인 등장
- 런 안 성장(경험치 / 레벨 업)
	- 적을 처치하면 경험치 보석 획득: 일반 2 / 강화형 3 / 중간 보스 20
	- 필요 경험치 12 + 6 × (레벨 - 1), 레벨 업 시 3개 중 1개 선택 (체력 회복 최대 30% / 골드 / 시간의 조각 / 총탄 / 총 / 방어구 강화)
- 체력 회복: 적 처치 시 하트 드롭(일반 2% / 강화형 3% / 중간 보스 확정, 최대 체력 20%), 상인 하트, 레벨 업 체력 회복


## 핵심 시스템

### 시계 연산
- 각 총탄은 시계의 숫자를 의미하는 실린더에 장착
- 장착된 총탄은 총탄 고유의 요구조건을 충족하는 시각의 실린더에 놓여야만 고유 효과와 특성 활성화
- 연산을 통해 각 총탄의 판정 시각을 조정 가능

# 궁극기
- 각 공격을 명중시키면 열기 게이지를 획득
- 열기의 게이지를 3칸 이상 획득하면 궁극기를 q키로 발동 가능
- 궁극기는 넓은 범위의 적을 모든 총탄을 소비하여 동시에 공격
- 궁극기 사용 시 무적 판정
- 궁극기 사용 시에 현재 활성화된 총탄의 효과와 특성의 효과 모두 적용
-> 화려한 액션을 통해 시각적 도파민을 제공 / 사용 타이밍을 조절 가능하게 함으로서 전략적 재미 전달

## 대쉬 회피
- 캐릭터는 최대 3회까지 대쉬 횟수 저장 가능
- 대쉬 횟수는 시간에 따라 자동적으로 충전
- 대쉬 사용 시 무적 판정이며, 적의 공격을 대쉬로 직접 회피할 경우 닷지 액션 발동
- 닷지 액션 발동 시 짧은 시간 치명타 보정을 획득하고, 주변 시간이 느려지는 연출을 통해 피드백 전달 (레퍼런스: 젠레스 존 제로 닷지 액션)




## 빌드 시스템
- 캐릭터가 가지는 속성: 방어력, 체력, 치명타 확률, 치명타 피해, 데미지, 이동속도, 열기(궁극기 게이지) 
- 보상에 따른 각 속성의 분배 
	- 총탄: 데미지, 다양한 고유 효과
	- 방어구 강화: 방어력, 체력 
	- 총: 치명타 확률, 치명타 피해

### 총탄 
- 활성화 조건을 충족하는 시각 실린더에 장착 되어야만 고유 효과와 특성 활성화
- 각 총탄의 등급에 따라 강력한 고유 효과 존재
- 0~2개의 연산 슬롯으로 판정 시각 조정 가능
- 2개의 특성 존재 
- 특성과 판정 시각의 전략적 운용을 통해 빌드 성장을 자극하는 것이 핵심 목표

### 총
- 왼손과 오른손에 장착 가능
- 예비 인벤토리가 존재하는 총탄이나 연산과 다르게 2개 이상 소지 불가능(새로운 총 획득 시 기존 총을 버려야만 장착 가능)
- 왼손 / 오른손 장착에 따라 효과가 달라짐. -> 부가적인 전략 요소로 작동
- 총마다 고유 효과와 등급 존재
- 총이 액티브 스킬을 활성화 하여 캐릭터는 최대 2개의 추가 기술 보유 가능

### 연산
- 총탄의 활성화 조건 조정을 좀 더 유연하게 만들고, 부가적인 전략요소로 작동 가능
- 각 총탄의 슬롯에 장착하여 총탄의 판정 시각을 조정(발사하는 순서엔 영향을 주지 않음)
- 1~3 의 숫자와 사칙연산을 조정하여 유저의 계산 체감이 너무 복잡해지지 않도록 설계

- 세부 연산 규칙
	- 사칙 연산의 기본 연산 규칙을 따르지 않음 -> 슬롯 순서를 우선 시 하여 적용
	- 나머지는 기존 PPT 그대로 반영

## 아웃게임 성장 시스템
- 메인 로비를 살바토르 달리의 기억의 지속을 모티브로 한 서부 마을로 구성
- 게임을 진행하며 스테이지가 클리어 될때마다 성장 요소가 조금씩 해금
- 해금되는 성장요소
	- 캐릭터 스탯 성장 / 고유효과
	- 새로운 아이템(총탄, 총)
	- 코스튬(캐릭터와 같이 새로운 궁극기나 기술 사용(레퍼런스: 세피리아 코스튬))
- 캐릭터의 스탯 성장 노드를 인 게임에서 획득 가능한 시간의 조각을 통하여 강화 가능
