# 11:59 简体中文 用语集 (zh)

`docs/loc_glossary.md`(한국어 → English) 의 중국어 열. 사전 `Game/Assets/Resources/Lang/zh.json`. 번역 전에 정하고 끝까지 지킴.

## 문체 (风格)

| 대상 | 中文风格 |
|---|---|
| UI · 안내 | 简洁、友好，用"你"。按钮 · 标签尽量短（2~6 字） |
| 보스 패턴 안내 | 短促祈使句 + "！"，保留 " — " 前后结构 |
| 고양이 | 西部枪手，话少、生硬、短句（"哼。""少废话。"），不用语气词堆砌 |
| 거울 속 고양이 | 平静、温柔，语气轻，少修饰 |
| NPC | 被时间侵蚀的梦幻存在：半忘半记，缓慢柔和，多用"……吧""好像"之类的停顿（但省略号一律写 ASCII `...`） |
| 꿈 컷 설명 | 短名词短语，分镜口吻（"布满皱纹的手在上发条（特写）"） |

## 符号 · 格式

- 省略号：原文 `...` 的点数原样保留为 ASCII 点（`......` → `......`），不改成 `……`。
- `{0}` `{1}` 全部保留，可调换语序。`<color=…>` `<size=…>` `<b>` `<i>` 原样保留、成对。
- ` · ` · ` — ` · `×` `÷` `+` `−` · 双空格保持原样；`\n` 行数与原文一致；首尾无空格。
- 中文正文用全角标点 `，。！？：（）`；原文有引号时用 `「」`。
- 数字单位：UI 数字后 `초` → `秒`；`m` 原样；`%` 原样；`발` → `发`；`칸` → `格`；`개` → `个`；`회/번` → `次`。
- 时钟时刻：`{0}시` → `{0}点`；`판정 {0}시` → `判定{0}点`；`{0}시 칸` → `{0}点格`；`발사 시각 {0}시` → `发射时刻{0}点`。
- 按键：Space · Tab · Esc · E · Q · WASD · M 保持拉丁字母；좌클릭/우클릭 → 左键/右键（句中可写 鼠标左键/右键）；휠 클릭 → 中键。
- Enum.csv 中的设计占位词 `Value` `Value2` `CondValue` `Duration` 原样保留。
- 游戏名 "11:59" 永不翻译。
