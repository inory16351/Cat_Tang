# 튜토리얼 기획서용 조사 (2026-11-27, 코드 기준)

튜토리얼 기획서를 만들 때 쓸 사실 정리. 주요 파일: `Game/StoryRun.cs`(SR) / `UI/TutorialGate.cs`(TG) / `UI/StoryOverlay.cs`(SO) / `UI/InventoryScreen.cs` / `Game/VillageStory.cs` / `UI/GameUI.cs` / `Game/StoryPractice.cs` / `Core/Meta.cs`.

## 1. 전체 흐름

### 새 저장 슬롯
- `Meta.FirstRunPending`: 판 0번 / 클리어한 장 0개인 슬롯(Meta.cs:140). 이런 슬롯은 마을을 건너뛰고 바로 1장 전투로 시작한다.
- `StoryRun.OnRunStart`(SR:58-64)가 판마다 붙이는 것:
  - 판 1: `StoryRun1`.
  - 판 2: `StoryHints`. 시너지 안내를 볼 때까지 다음 판에도 계속 붙는다.
  - 판 1을 뺀 모든 판: `OpHints` / `DodgeHints`. 각 키를 볼 때까지 붙는다.

### 판 1 (`StoryRun1`, SR:139-537)
1. 오프닝 = 꿈1 '멈춘 손'(opening 키를 아직 안 봤을 때만).
2. 깨어남 연출(두통). 대사 "고양이#두통::윽...... 꿈인가......." / "머리가 아프군.......".
3. 적이 생성된 뒤 시간 정지 대사 "......지금은 잠자리 같은 걸 신경 쓸 때가 아니다." / "우선 급한 불부터 해결하자고.".
4. 총 돌려 뽑기 1초 → 조작 시작.
5. 자막: "WASD  이동     좌클릭  사격     Space  대시".
6. 판 1 동안 미니맵 숨김.
7. 첫 방 클리어 뒤 몰려오는 적 3웨이브(8 → 12 → 16, 2~3웨이브는 강화형).
8. 쓰러짐 연출(슬로 / 심정지음 / 화이트아웃) → `tut1` 기록 → 마을. 판 1에서 죽어도 같은 연출로 가고, 결과 화면은 없다.

### 마을 첫 대화 (VillageStory "intro", VillageStory.cs:22-37)
- 14줄. 뻐꾸기 "또 왔구나." / "여긴 바늘이 열두 시에 닿지 않는 곳이야."로 시작한다.
- 끝: "고양이#결의::난... 이 마을을 벗어나야 해..." / "…하고 나서 후회하는 게 아무것도 하지 않는 것보단 나을 테니...".
- 대화 뒤 카메라가 시간의 문을 비추고 길 안내 화살표 "시간의 문"을 표시.

### 1장 클리어 뒤 (꿈2, VillageStory.cs:41-47, 206-227)
- "젠장... 또 이상한 꿈을 꿨군..." → 뻐꾸기 6줄.
- 기억의 방 공개 → "손님이 온 모양이던데....." → 다리 연결 → 의상실 공개.
- 화살표 2개: "기억의 방" / "의상실".

### 시설 첫 방문 안내 (GameUI.cs:1164-1188, 키 `tut_fac_{시설}`)
- 기억의 방: "시간의 조각으로 능력 강화\n더 강해진 기억으로 재도전".
- 의상실: "코스튬은 캐릭터에게 특별한 능력을 더해줍니다.\n새로운 의상을 통해 당신의 매력을 뽐내세요.".

### 시설 해금 (Meta.cs:129-131, `FacilityUnlockChapter = {1,2,2,1}`)
- 기억의 방 / 의상실: 1장 클리어.
- 총포상: 2장 클리어 + `q2_gun` 퀘스트.
- 탄약 공방: 2장 클리어 + `q2_ammo` 퀘스트.
- HANDOFF 예전 절의 {1,3,2,2}는 옛 값이다.

### 판 안 길 안내 (RunManager.cs)
- 방 클리어 시 토스트 "다음 방으로" + 다음 방 문에 "다음 방" 표시(:347, 651-659). 길을 막는 소품은 부순다.
- 보상 문마다 "<이름> 문" 또는 "최종 보스" 표시. 모두 화면 밖이면 "보상 문 N개" 하나로 합친다(:605-620).

### 기능 잠금 (TG:1-62)
- 적용 조건: 클리어한 장 0개 + `tut2`를 안 봄 + 튜토리얼 슬롯. 예전 저장은 처음부터 전부 열려 있다.
- 잠긴 기능은 입력을 무시하고 HUD도 숨긴다. 해금되는 순간 HUD가 금빛 번쩍임과 함께 튀어나온다.
- 도움말 줄에는 배운 키만 나온다.

| 기능 | 해금 시점 | 키 |
|---|---|---|
| 인벤토리 Tab | "Tab 키를 눌러…" 첫 안내(첫 탄 / 연산 / 시너지) | gate_tab |
| 판정 / 활성화 HUD 줄 | 판정 시각 안내 뒤 | gate_judge |

## 2. 안내 (판 2부터)

### 공통 UI
- `Hint` / `HintAt`: 시간 정지 + 대상 스포트라이트. E나 클릭으로 닫음, 키 표시는 "E · 클릭  계속".
- `HintAtSteps`: 본문을 0.6초마다 한 줄씩 표시.
- `TryAt`(직접 해 보기): 시간은 흐르고, 대상 칸에 노란 테두리가 맥동하며, 아래에 자막.
- `TutAllow`가 걸려 있으면 유도한 조작만 허용. 나머지는 거절하고 "노란 테두리로 표시된 곳에서 해 주세요" + `ui_deny` 소리 + 흔들림. 닫기 버튼 / 다른 창 열기도 거절.
- Tab 유도 문구: "Tab 키를 눌러 인벤토리를 여세요.".
- 편집이 필요한 안내는 전투가 끝날 때까지 미룬다. `StoryHints.busy`로 안내끼리 겹치지 않는다.

### a. 총알 시계 (`tut2_clock`)
- 발동: 첫 사격. HUD 실린더를 스포트라이트.
- 제목 "총알 시계". 본문 "각 실린더의 칸은 시계를 의미합니다.\n총을 쏠 때마다 시간은 흘러가고,\n흘러가는 시간에 따라 특별한 효과를\n받을 수 있을지도 몰라요!".

### b. 판정 시각 (`tut2_cond`, 4쪽)
- 발동: 기본 탄이 아닌 탄을 처음 얻음 → Tab 유도 → 인벤토리.
- 1/4 "탄환 시계": "탄환 시계의 12칸은 각각 하나의 시각이에요.\n탄은 1시 칸부터 12시 칸까지 차례로 발사돼요."
- 2/4 "판정 시각": "탄이 놓인 칸의 시각이 그 탄의 '판정 시각'이에요.\n판정 시각이 탄의 시각 조건에 맞으면 탄이 활성화돼요."
  - 실시간 줄: "지금 '{0}'은 {1}시 칸에 있어요 → 판정 시각 {2}시 · 조건 '{3}' → 맞아요 / 아직 안 맞아요".
  - 탄이 보관함에 있을 때: "지금 '{0}'은 보관함에 있어요 → 탄환 시계 칸에 넣어야 판정 시각이 생겨요. (조건 '{1}')".
- 3/4 직접 해 보기: "'{0}'을 조건에 맞는 칸으로 끌어 옮겨 보세요."
  - 그 탄을 조건에 맞는 칸으로 옮기는 것만 허용.
  - 성공: "활성화됐어요! 금빛 칸의 탄은 특성과 고유 효과가 켜져요."
  - 이미 활성화됨 / 전투 중 / 맞는 칸 없음이면 건너뜀.
- 4/4 "확인하는 곳": "탄에 마우스를 올리면 시각 조건과 지금 판정 시각을 볼 수 있어요."
- 끝나면 판정 줄 해금.

### c. 판정 +N 줄 (`tut_judge_add`)
- 발동: 이웃 칸 판정 +N 효과가 있는 탄을 가짐.
- 7초 자막: "'{0}'이 활성화되면 양옆 칸 탄의 판정 시각이 +{1} 돼요. 연산을 다 계산한 다음에 더해져요."

### d. 불릿 파티 (`tut2_heat`)
- 발동: 열기가 가득 참.
- 대사 "흠, 지금이다......." / "본때를 보여주지!" → Q 해금 → 0.3배속 + "Q 키를 누르세요." → 사용 뒤 "하핫, 아직 실력이 녹슬지 않았군!".

### e. 총 스킬 (`tut2_skill`)
- 발동: 시계 안내 뒤 적이 3.5m 안으로 들어옴.
- 제목 "백스텝 샷". 본문 "우클릭하면 뒤로 물러나며 두 발을 쏴요.\n물러나는 순간에는 공격을 받지 않아요.\n한 번 쓰면 6초 뒤에 다시 쓸 수 있어요."
- 0.3배속 + "우클릭으로 백스텝 샷을 써 보세요." 사용하거나 6초가 지나면 끝.
- cond / heat / skill을 모두 보면 `tut2` 기록.

### f. 시너지 (`tut_synergy`)
- 발동: 특성 1단계 달성 → Tab 유도 → 능력치 탭.
- 본문 "같은 특성의 탄을 함께 장전하면 시너지가 생겨요.\n2 · 4 · 6발을 모을 때마다 효과가 한 단계씩 강해져요.\n지금 켜진 시너지는 이곳에서 확인할 수 있어요."
  - **기획서 정리용 주의**: 특성 단계는 이제 '교체'다. "한 단계씩 강해져요"라는 문구는 그대로 둬도 의미가 맞는지 확인할 것.

### g. 연산 (OpHints)
- 문 안내 (`tut_op_door`): 연산 보상 문이 처음 보일 때 5초. "연산 문: 탄의 판정 시각을 바꾸는 연산을 얻을 수 있어요."
- 본 안내 (`tut_op`): 첫 연산을 얻음 → 입력이 0.4초 잠잠해질 때까지 대기 → Tab 유도. 6쪽:
  1. "연산은 탄에 끼워 판정 시각을 바꾸는 계산이에요.\n탄을 다른 칸으로 옮기지 않아도 조건을 맞출 수 있어요."
  2. "끼우는 곳": "탄을 클릭하면 '탄 강화' 창이 열려요.\n보관함의 연산을 이 칸으로 끌어 끼우면 돼요." (+ "기본 '탄환'에는 연산 칸이 없어요.")
  3. "계산 순서"(한 줄씩): "판정 시각은 칸의 시각에서 시작해서, 위 칸의 연산부터 차례로 계산해요.\n예) 3시 칸 → ×2 → 6 → +1 → 7시\n순서를 바꾸면 3 → +1 → 4 → ×2 → 8시가 돼요."
  4. "계산 규칙"(한 줄씩): "나누어떨어지지 않으면 반올림해요. 예) 5시 칸 ÷2 → 2.5 → 3시\n12를 넘거나 0 이하가 되어도 그대로 둬요. 예) 9시 칸 ×2 → 18시 · 1시 칸 −2 → −1시\n그래서 '음수 시각' 같은 조건도 맞출 수 있어요."
  5. "미리 보기": "이 줄은 지금 끼운 연산으로 이 탄이 활성화되는 칸을 보여 줘요.\n금빛 칸에 놓으면 활성화돼요.\n연산은 판정 시각만 바꿔요. 쏘는 순서는 그대로 1시부터 12시예요."
  6. 직접 해 보기: "연산을 끼워 이 탄을 활성화해 보세요."
     - 허용: 연산을 연산 칸에 끼우기 / 칸끼리 바꾸기 / 칸에서 보관함으로 떼기.
     - 완료 "활성화됐어요!". 가진 연산으로 활성화할 수 없으면(`Reachable`) 건너뜀.

### h. 극한 회피 (`tut_justdodge`)
- 발동: 플레이어 9m 안에서 주황 십자 번쩍임.
  - 판 2: 중간 보스 방부터 또는 스테이지 2 이상.
  - 판 3부터: 처음 보는 번쩍임 아무거나.
  - 연습 모드에서는 발동하지 않음.
- 본문 "공격 직전에 주황 십자가 번쩍여요.\n그 순간 대시로 피하면 극한 회피가 발동해요.\n잠깐 시간이 느려지고, 그동안 쏘는 탄은 치명타가 잘 터져요."
- 이어서 0.25배속 1.2초 + "주황 십자가 번쩍이는 지금 {대시 키}!" → 성공 시 "극한 회피!".

### 코드에 없는 것
- 장전 / 문 / 지도 / 상점 / 레벨 업 전용 안내는 없다. 토스트와 화살표뿐이다.

## 3. 보스 패턴 연습
- 설정 위치: 게임 탭 "보스 패턴 연습 (장별)" 1~5장 체크(`bossPractice{ch}`).
- 장별 스토리 맵 키: plaza / platform / lake / workshop / ward.
- 의도한 동작:
  - 스토리 맵을 대사와 연출 없이 기믹 구간만 진행.
  - 화면에 "보스 패턴 연습" / "Enter 길게 — 연습 끝내기" 표시.
  - Enter를 1.2초 누르면 종료.
  - 체력은 1 아래로 안 떨어지고, 25% 미만이면 다시 채움.
  - 기록 / 골드 / 경험치 / 하트 없음.
- **버그**: `StoryPractice.Pending()`과 `Play()`를 아무도 호출하지 않는다. `RunManager.EnterDoor`(:686-700)는 `StoryMap.Pending`만 본다. 그래서 지금은 설정을 켜도 판에서 아무 일도 일어나지 않는다. 연결이 필요하다.
