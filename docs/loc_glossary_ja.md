## 기호 · 형식

- 대사 말줄임은 ASCII `...` 그대로, 개수도 원문 그대로 (`......` → `......`). `……` 로 바꾸지 않음. `…`(한 글자)는 원문에 있을 때만.
- 문장부호: 일본어 문장은 「。」「、」. 느낌표 · 물음표는 전각 「！」「？」. 원문 `..??` 같은 겹친 기호는 그대로.
- 따옴표: 원문이 따옴표를 쓸 때만 「」(원문 `'…'` `"…"` → 「…」).
- 자리 표시 `{0}` `{1}` … 전부 유지(어순 따라 위치만 이동). 리치 텍스트 태그 그대로 · 짝 유지.
- ` · ` · ` — ` · `×` `÷` `+` `−` · 겹친 공백(키 안내 두 칸) 그대로. 앞뒤 공백 없음.
- 숫자 단위: `초` → `秒`, `발` → `発`, `칸`(시계 · 실린더) → `マス`, `개` → `個`/`つ`, `회`/`번` → `回`, `%` · `m` 그대로.
- `{0}시` (시계 칸의 시각) → `{0}時`. `판정 {0}시` → `判定 {0}時`, `{0}시 칸` → `{0}時のマス`.
- 키 이름: `좌클릭` 左クリック · `우클릭` 右クリック · `휠 클릭` ホイールクリック · Space · Tab · Esc · E · Q · WASD · M 그대로.
- Enum.csv 의 `Value` `Value2` `CondValue` `Duration` 은 글자 그대로 둠.
