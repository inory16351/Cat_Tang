# UI / 환경설정 기획서용 조사 (2026-11-27, 코드 기준)

경로는 `Game/Assets/Scripts/` 기준.

## 1. 화면과 흐름

### 로비 (`UI/LobbyScreen.cs`)
- 인트로 8.2초. 클릭 / 키로 건너뜀.
  - 고양이 얼굴 근접 → 잉크 선 → 줌아웃(1.9 → 1.06) → 색 번짐 → 타이틀 도장과 흔들림 → 메뉴 슬라이드.
- 메뉴: "새로 시작" / "이어하기"(쓴 슬롯이 없으면 회색) / "설정" / "게임 종료".
- 패널 1320×880, 본문 1060×480, "뒤로" 버튼.
- 저장 슬롯 3개(`Meta.SlotCount`), 카드 222×372.
  - 제목 "기억 {n}".
  - 진행: "{n}장까지 넘음" / "아직 1장 앞" / "11:59를 넘음".
  - 이어서 "시간의 조각 N · 판 N번", 마지막 플레이 시각. 빈 슬롯은 "비어 있는 기억".
  - 버튼: "여기서 시작" / "덮어쓰기"(한 번 더 누르면 "정말 덮어쓸까?").
  - 이어하기 화면에는 "지우기"(한 번 더 누르면 "한 번 더 = 지움").
- 종료 확인: "정말 종료하시겠습니까?" "예" / "아니오". 슬롯을 고르면 라벤더 안개로 전환 → 마을.

### 마을
- HUD는 방 이름 줄 "여관 앞 마을"만 표시.
- 도움말 "WASD 이동 · Space 대시 · E 들어가기 · Tab 인벤토리 · M 지도".
- 시간의 문 창 1300×900.
  - 장 5줄, 상태 "넘음 ✓" / "이번 목표" / "잠김".
  - 버튼 "출발 — 1장부터". 매번 1장부터 시작, 목숨 1개.
- 마을 지도(M): 해금한 섬 / 다리 / 시설만 표시.
- 길 안내 화살표: 노란 화살표가 통통 튀고 위에 이름 표시. 대상이 화면 밖이면 가장자리에 붙음.

### 판 HUD (`GameUI.cs`, `UI/HudView.cs`)
- 왼쪽 위
  - 체력 바 + HP 숫자.
  - 그 아래 대시 아이콘 3개(아래부터 차오름). 고양이 머리 위에도 "<<<" 표시(`HeadDash`).
- 오른쪽 위: 골드 / 시간의 조각, 조각은 "N (+이번 판)".
- 가운데 위
  - 진행 줄 "{장}장 · 스테이지 {s}/4 · 방 {r}/{n}". 중간 보스 방은 "중간 보스", 보스 방은 보스 이름.
  - 전투가 끝나면 "· 다음 방 · 문으로"가 붙음.
  - 보스 체력 바 980×86, 흰 잔상 표시.
- 가운데 아래
  - 탄환 시계 HUD(화면 높이 25%): 열기 3칸 / 실린더 2개 × 6발 / 시곗바늘. 아래에 경험치 바 + 레벨 배지.
  - 글줄: "다음 {s}시 · {탄} · 판정 {j}시 · 활성화/비활성화" 또는 "장전 중…" / "열기 x/3"(가득 차면 "Q 불릿 파티!") / "총 스킬 {n}초/준비".
- 왼쪽 아래: 배운 키만 나오는 도움말.
- 가운데 아래: 상호작용 "E {대상}".
- 왼쪽: 켜진 특성(`TraitHud`). 단계 표시 2 / 4 / 6.
- 오른쪽 아래: 미니맵.
  - 크기 250(좁은 화면은 170).
  - 적 점 / 문 / 고양이와 조준 바늘 표시. 전투 중에는 반투명.
- 기타
  - 불릿 파티가 준비되면 화면 가장자리에 불꽃.
  - 조준 커서 84px, 아래 색을 반전.
  - 튜토리얼 동안은 아직 안 배운 기능의 HUD를 숨김.

### 인벤토리 Tab (1760×940)
- 왼쪽: "탄환 시계" 12칸 + "왼손 · 짝수" / "오른손 · 홀수".
- 가운데: "보관함" 4×3(12칸) + "끌어서 팔기".
- 오른쪽: "설명" / "능력치" 탭.
- 전투 중에는 보기만 가능: "전투 중에는 교체할 수 없습니다".

### 탄 강화 창 (1240×760, 탄 클릭)
- 연산 칸 "위 (먼저 계산)" / "아래".
- "보관함의 연산".
- 미리 보기 "이 탄이 활성화되는 칸 (지금 연산 기준)".

### 레벨 업
- "레벨 업!  Lv N — 하나 고르기", 게임 일시 정지.
- 카드 430×520, 간격 470, 버튼 "고르기", "다시 뽑기 (1회)".
- 총을 고르면 교체 창: "왼손에 쥐기" / "오른손에 쥐기" / "버리기 (바닥에 둠)".

### 상인 (1400×820, 배너 "떠돌이 상인")
- 카드 3열(400×240), 버튼 "{가격} 골드" / "판매됨".
- "하트 · 체력 N%", "새로고침 (N 골드)".
- 상인이 화면 밖이면 동전 아이콘 가장자리 화살표.

### 보상 문
- 나무 문 위에 보상 아이콘.
- 전투가 끝나면 문마다 작은 화살표. 모두 화면 밖이면 "보상 문 N개" 하나로 합침.

### 지도 M
- 양피지 판에 방 타일 / 복도 / 중간 보스와 보스 아이콘 / 문 / 고양이 머리.
- 게임을 멈추지 않음. Esc로도 닫힘.

### 일시 정지 Esc (1180×900)
- 배너 "잠시 멈춤", 머리 "환경설정", 설정 4탭(1060×500).
- 마을에서만 "슬롯 · 넘은 장 · 시간의 조각" 줄.
- 버튼 "계속하기" + 마을에서는 "메인 로비로", 판에서는 "전투 포기".
- 포기 확인 760×440: "전투를 포기하고 마을로 이동하시겠습니까?" / "이번 판에서 얻은 시간의 조각 N개만 가져갑니다".

### 결과 화면 (1000×620)
- 배너: "{ch}장 돌파" / "11:59를 넘었다" / "시간에 삼켜졌다".
- 본문: "시간의 조각 +N (보유 N)" / "골드는 사라진다." / 시설 해금 / "다음 판은 N장까지…".
- 버튼 "마을로".

### 대화창
- 왼쪽 고양이, 오른쪽 상대 초상화. 이름표는 말하는 쪽 아래. 대화 중에는 HUD 숨김.
- 대사 형식 "이름#표정::대사". 표정 효과 예: 두통 = 흔들림 + 빨간 번쩍임.
- E / Space / Enter / 클릭으로 넘김. 글자가 나오는 중에 클릭하면 다음 줄.

## 3. 조작 (`Core/KeyBinds.cs`, `UI/KeyBindsUI.cs`)
| 행동 | 기본 키 |
|---|---|
| 위로 이동 | W |
| 아래로 이동 | S |
| 왼쪽으로 이동 | A |
| 오른쪽으로 이동 | D |
| 대시 | Space |
| 상호작용 | E |
| 인벤토리 | Tab |
| 지도 | M |
| 불릿 파티 | Q |
| 총 스킬 | 우클릭 |

- 고정 키: Esc / 좌클릭 / 대사 넘김.
- 지정할 수 있는 마우스 버튼: 우클릭 / 휠 클릭 / 마우스 4 / 마우스 5.
- 이미 쓰는 키를 고르면 두 행동이 키를 맞바꿈. 저장값에 중복이 있으면 뒤쪽 행동을 기본값으로 되돌림.
- 화면 배치
  - 2열 × 5줄. 줄 470×50, 키캡 190×46.
  - 키캡을 누르면 "키를 누르세요" 대기 상태. Esc나 다른 곳 클릭으로 취소.
  - 바꾼 키는 연한 금색으로 표시.
  - 안내 문구 "키 칸을 누르고 새 키를 눌러요. 이미 쓰는 키면 서로 바뀌어요. (Esc 취소)", 버튼 "기본값으로".
- **어긋남**
  - HUD 도움말 줄과 "E" 상호작용 표시는 기본 키로 박혀 있다(`KeyBinds.Name`을 쓰지 않음).
  - 도움말에 아직 "Esc 포기"라는 문구가 남아 있다.

## 4. 언어 (`Core/Loc.cs`)
- 목록 8개: 한국어 / English / 日本語 / 简体中文 / Français / Deutsch / Русский / العربية.
- 실제 사전 파일은 `en.json`(1,707개)과 `zh.json`뿐이다. 나머지 언어는 고르면 한국어로 나온다.
- 번역 방식
  - 코드의 한국어가 원문. `LText` / `WorldLabel`이 `Loc.T`를 불러 쓴다.
  - 찾는 순서: 통째로 → 줄마다 → {0} 틀 → 숫자 틀. 못 찾은 문구는 `Loc.Misses`에 모은다.
  - 아랍어는 오른쪽에서 왼쪽으로. 언어별 글꼴은 `LangFonts`.
